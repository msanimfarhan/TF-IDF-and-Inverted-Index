# 🔍 Information Retrieval Search Engine

A Python-based Information Retrieval project that explores how search engines index, retrieve, and rank documents using classic IR techniques.

## 🚀 Features

* 📄 Term-Document Incidence Matrix
* 🔎 Inverted Index Construction
* ⚡ Boolean Retrieval (AND, OR, NOT)
* 📊 TF-IDF Ranked Retrieval
* 🎯 Cosine Similarity Scoring
* 📚 Whoosh Search Engine Integration

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Whoosh

## 🎓 What I Learned

Through this project, I gained hands-on experience with:

* Text preprocessing and tokenization
* Document indexing techniques
* Boolean and ranked retrieval models
* TF-IDF weighting
* Search result ranking and evaluation
* Search engine fundamentals

## 📌 Sample Query

```python
ranked_retrieval("great battery life")
```

Returns the most relevant documents ranked by similarity score.
